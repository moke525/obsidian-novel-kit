功能简介

Ribbon 房子图标。仪表盘，不是第二套正文编辑器。

本页属于「创作面板」，按 功能简介 → 界面元素 → 操作方法与步骤 → 键盘操作 → 命令行 → 注意事项 组织，末尾的「其他」放补充说明与相关页面。

界面元素

界面元素一览

  • Ribbon 房子图标
  • 当前作品、KPI、每日码字 / 热力图、词频、待办等组件
  • 右上角齿轮 → 主页模板编辑器

组件

组件操作
当前作品看进度，点进创作面板；从这里新增 / 重命名 / 删除作品登记
KPI全库字数、今日净增量（last−start）与实际增量（max−start）
每日码字 / 热力图只统计当前作品工作区里的正文
词频当前作品用词
待办写在 System/home.json，关库再开还在
网页表格填 URL → 获取；会联网请求该地址
每日一句必须指定库内某篇 md 当数据源
作品日志记录命运文件增删与关联，分类名显示为「命运」

操作方法与步骤

怎么打开

Ribbon home，或命令「打开创作主页」。

改布局

  1. 右上角齿轮 → 主页模板。窗口可拖、可缩放。
  2. 左侧：页面背景图与高度、布局类型、组件列表、选中节点属性。窄屏收成抽屉。
  3. 画布上拖组件换位置或换容器。布局：list 单列、grid 自适应、splitPanel 两栏、tabs 页签。

首次按视口挑默认模板：宽屏多层 splitPanel，窄屏单列（避免 390px 再切两栏只剩几十像素）。两套都保留，可随时切回。

键盘操作

按键作用
Ctrl/Cmd+P打开 Obsidian 命令面板，按名称搜索并执行本页「命令行」里的命令（Obsidian 自带，不是插件默认快捷键）
Enter提交当前输入 / 确认（各类弹窗、内联输入、列表项）
Esc取消编辑 / 关闭弹窗或抽屉

所有视图级快捷键在输入框、正文编辑态内都不触发（isTypingTarget 判定）；隐藏或失焦的面板也不响应。下表的「命令行」是另一套入口，两者不要混为一谈。

注意事项

Warning

字数对不上时，先看顶部选中的是不是你以为的那部作品，以及稿子是否在该作品的 正文/ 下。

通用限制

  • 本插件 manifest 声明 isDesktopOnly: true，最低 Obsidian 1.8.7；笔记始终是明文 Markdown，插件只读写 frontmatter 与 System/*.json。
  • 插件没有为任何命令注册默认快捷键，需要快捷键请到「设置 → 快捷键」按命令名搜索后自行绑定。
  • 视图级快捷键只在画布 / 视图聚焦且可见时生效，输入框内不触发。
