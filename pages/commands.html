功能简介

命令面板（Ctrl/Cmd+P）搜中文名即可。Ribbon 可在设置 → 小说创作 → 功能入口里逐个关掉。

本页属于「开始」，按 功能简介 → 界面元素 → 操作方法与步骤 → 键盘操作 → 命令行 → 注意事项 组织，末尾的「其他」放补充说明与相关页面。

界面元素

界面元素一览

  • 命令面板 Ctrl/Cmd+P
  • 左侧 Ribbon
  • 设置 → 快捷键 / 设置 → 小说创作 → 功能入口
  • 编辑器与文件树右键菜单

操作方法与步骤

本功能的操作入口与细则见「界面元素」以及 命令与入口；本页正文以规则与数据说明为主。

键盘操作

按键作用
Ctrl/Cmd+P打开 Obsidian 命令面板，按名称搜索并执行本页「命令行」里的命令（Obsidian 自带，不是插件默认快捷键）
Enter提交当前输入 / 确认（各类弹窗、内联输入、列表项）
Esc取消编辑 / 关闭弹窗或抽屉

所有视图级快捷键在输入框、正文编辑态内都不触发（isTypingTarget 判定）；隐藏或失焦的面板也不响应。下表的「命令行」是另一套入口，两者不要混为一谈。

命令行

本页下面三张表按功能模块索引命令：小说创作、其它模块、编辑器 / 文件树右键入口。每条命令的中文名与命令 ID 对照表，列在对应功能页的「命令行」章节。

以上命令均没有默认快捷键：源码里的 addCommand 没有声明 hotkeys，需要快捷键请自行到「设置 → 快捷键」绑定。命令面板本身由 Obsidian 提供，不是插件命令。

其它模块

  • 码字：打开面板、给当前正文设目标/冲刺、四处字数开关。
  • 写作模式：打开菜单、关闭、切到某一预设。
  • 历史快照：打开面板、存档当前、清理。
  • 高级搜索：停靠面板、浮动窗。
  • JSON Studio：打开当前 JSON / 新标签。
  • CSS 片段：打开编辑、重新加载。
  • 文件树排序：重新应用。
  • 取名、手机预览：各一条打开命令。
  • 导出：打开导出面板、导出当前文件、导出当前文件夹（Ribbon / 设置里无入口，命令仍已注册）。

编辑器 / 文件树右键（需已打开作品）

  • 正文：添加伏笔、添加到标记 / 回收标记、关联到情节/场景、编辑/清除故事线、提取灵感/便签/高亮。
  • 功能开关：字数四处显示、高亮总开关。
  • 文件树：码字目标、条目样式、隐藏 _index 时「打开文件夹文件」。

注意事项

Warning

无活动作品时，多数创作命令会提示先注册工作区。共享源卷上的写入菜单不可用。

通用限制

  • 本插件 manifest 声明 isDesktopOnly: true，最低 Obsidian 1.8.7；笔记始终是明文 Markdown，插件只读写 frontmatter 与 System/*.json。
  • 插件没有为任何命令注册默认快捷键，需要快捷键请到「设置 → 快捷键」按命令名搜索后自行绑定。
  • 视图级快捷键只在画布 / 视图聚焦且可见时生效，输入框内不触发。
