高亮

功能简介

全局装饰规则，对所有已注册作品生效。入口在设置 → 高亮设置，不在创作面板 Tab。

本页属于「全局能力」，按 功能简介 → 界面元素 → 操作方法与步骤 → 键盘操作 → 命令行 → 注意事项 组织，末尾的「其他」放补充说明与相关页面。

界面元素

界面元素一览

  • 设置 → 高亮设置
  • 规则类型列表
  • 正则 / 文件名 / 注释 / 敏感词 / 对白规则项

规则类型

  • 正则、文件名（设定名等）、注释、敏感词、对白（对白着色 / 弱化旁白）、长句。
  • 标记高亮：标记账本的源头/回收选区（旧名曾叫伏笔/钩子样式）。
  • 伏笔高亮：正文里挂到命运节点的选区。点高亮可打开已开着的伏笔总览。

操作方法与步骤

操作

  • 命令「开关高亮设置」一键关装饰。
  • 选区「提取为高亮文件 / 高亮注释」。
  • 词表来自全部已注册作品 + 共享源卷。默认排除 System/ 和点开头的文件夹。
  • 旧作品若有 System/highlight.json，需要时导入一次到全局设置。

关「伏笔面板」入口会停伏笔高亮；关「标记面板」会停标记高亮。互不影响。

键盘操作

按键作用
Ctrl/Cmd+P打开 Obsidian 命令面板，按名称搜索并执行本页「命令行」里的命令（Obsidian 自带，不是插件默认快捷键）
Enter提交当前输入 / 确认（各类弹窗、内联输入、列表项）
Esc取消编辑 / 关闭弹窗或抽屉

所有视图级快捷键在输入框、正文编辑态内都不触发（isTypingTarget 判定）；隐藏或失焦的面板也不响应。下表的「命令行」是另一套入口，两者不要混为一谈。

命令行

在命令面板（Ctrl/Cmd+P）里搜「命令面板里的名称」这一列的中文名即可执行。下表同时给出命令 ID，方便在「设置 → 快捷键」里精确查找、以及在 data.json / 同步配置里核对。

命令面板里的名称命令 ID
开关高亮设置novel-toggle-highlight
提取选区为高亮文件novel-extract-filename
提取选区为高亮注释novel-extract-annotation

以上命令均没有默认快捷键：源码里的 addCommand 没有声明 hotkeys，需要快捷键请自行到「设置 → 快捷键」绑定。命令面板本身由 Obsidian 提供，不是插件命令。

注意事项

通用限制

  • 本插件 manifest 声明 isDesktopOnly: true，最低 Obsidian 1.8.7；笔记始终是明文 Markdown，插件只读写 frontmatter 与 System/*.json。
  • 插件没有为任何命令注册默认快捷键，需要快捷键请到「设置 → 快捷键」按命令名搜索后自行绑定。
  • 视图级快捷键只在画布 / 视图聚焦且可见时生效，输入框内不触发。
