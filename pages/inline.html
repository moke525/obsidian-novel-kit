功能简介

在任意笔记里插入可交互的时间线、表格、卡片。

本页属于「创作面板」，按 功能简介 → 界面元素 → 操作方法与步骤 → 键盘操作 → 命令行 → 注意事项 组织，末尾的「其他」放补充说明与相关页面。

界面元素

界面元素一览

  • ```novel-timeline / ```novel-table / ```novel-cards 代码块
  • 笔记内嵌视图与其工具栏

规则

  • 命令「插入时间线/表格/卡片视图块」在光标处插入骨架。
  • height 200–1600，默认 560。
  • 数据来自承载该块的笔记所属作品，不是你在面板里选中的作品。
  • 块内改列、筛选、分组、排序、条件格式、模板、时间线标记时段，只写回该块 height 与 config 两行。
  • 打开内联时间线配置时延迟落盘，避免写回关掉面板。
  • 搜索词、页码是临时状态，不写入代码块。
  • 没有 config 的块跟随作品存档。
  • 命运文件模板会带 novel-blueprint 块；命令面板没有「插入蓝图」项。

操作方法与步骤

本功能的操作入口与细则见「界面元素」以及 命令与入口；本页正文以规则与数据说明为主。

键盘操作

按键作用
Ctrl/Cmd+P打开 Obsidian 命令面板，按名称搜索并执行本页「命令行」里的命令（Obsidian 自带，不是插件默认快捷键）
↑ 或 ↓在叶子行间移动活动单元格并滚动到可见
Enter进入当前单元格编辑
Ctrl/Cmd+N在当前行后新建行（需允许行编辑且非只读）
Enter、Esc（单元格编辑态）保存并结束编辑 / 取消编辑
Ctrl/Cmd+F聚焦卡片搜索框并全选
← 或 ↑ 或 → 或 ↓在可见卡片间移动焦点；无选中时从第 0 张开始
Enter（卡片聚焦时）打开该卡片
Enter、Space（模板编辑器）选中模板项
Ctrl/Cmd+C 或 Ctrl/Cmd+V复制 / 粘贴选中项
Ctrl/Cmd+= 或 -放大 / 缩小时间刻度
Delete删除选中项
← 或 →微调选中项的时间
Space（播放面板）播放 / 暂停
→、←（播放面板）下一事件 / 上一事件
Esc（播放面板）关闭播放面板；播放面板打开时甘特不抢方向键

所有视图级快捷键在输入框、正文编辑态内都不触发（isTypingTarget 判定）；隐藏或失焦的面板也不响应。下表的「命令行」是另一套入口，两者不要混为一谈。

命令行

在命令面板（Ctrl/Cmd+P）里搜「命令面板里的名称」这一列的中文名即可执行。下表同时给出命令 ID，方便在「设置 → 快捷键」里精确查找、以及在 data.json / 同步配置里核对。

命令面板里的名称命令 ID
插入时间线视图块novel-insert-timeline-block
插入表格视图块novel-insert-table-block
插入卡片视图块novel-insert-cards-block

以上命令均没有默认快捷键：源码里的 addCommand 没有声明 hotkeys，需要快捷键请自行到「设置 → 快捷键」绑定。命令面板本身由 Obsidian 提供，不是插件命令。

注意事项

Warning

块在 A 作品的笔记里，读的就是 A 的 System，即使面板顶部正选着 B。

通用限制

  • 本插件 manifest 声明 isDesktopOnly: true，最低 Obsidian 1.8.7；笔记始终是明文 Markdown，插件只读写 frontmatter 与 System/*.json。
  • 插件没有为任何命令注册默认快捷键，需要快捷键请到「设置 → 快捷键」按命令名搜索后自行绑定。
  • 视图级快捷键只在画布 / 视图聚焦且可见时生效，输入框内不触发。
