功能简介

把 Novel-kit 装进桌面版 Obsidian。最低版本 1.8.7，manifest 声明仅桌面端。

本页属于「开始」，按 功能简介 → 界面元素 → 操作方法与步骤 → 键盘操作 → 命令行 → 注意事项 组织，末尾的「其他」放补充说明与相关页面。

界面元素

界面元素一览

  • 设置 → 第三方插件 / 社区插件市场
  • Ribbon 的房子（创作主页）与书本（创作面板）图标
  • 插件目录 <库>/.obsidian/plugins/novel-kit/

操作方法与步骤

社区插件市场

  1. 设置 → 第三方插件 → 关闭安全模式。
  2. 浏览，搜索 novel-kit，安装并启用。
  3. 左侧 Ribbon 应出现房子（主页）和书本（创作面板）。若没有，到设置 → Novel-kit → 小说创作检查总开关与 Ribbon 勾选。

手动安装

  1. 从 GitHub Releases 取 main.js、manifest.json、styles.css。
  2. 放到 <库>/.obsidian/plugins/novel-kit/。
  3. 启用插件。改过 manifest.json 后必须重启 Obsidian。

键盘操作

按键作用
Ctrl/Cmd+P打开 Obsidian 命令面板，按名称搜索并执行本页「命令行」里的命令（Obsidian 自带，不是插件默认快捷键）

安装过程不涉及插件内键盘操作。

所有视图级快捷键在输入框、正文编辑态内都不触发（isTypingTarget 判定）；隐藏或失焦的面板也不响应。下表的「命令行」是另一套入口，两者不要混为一谈。

命令行

本功能没有注册独立的命令面板命令，入口见上方「操作方法与步骤」与「界面元素」。全部命令清单见 命令与入口。

以上命令均没有默认快捷键：源码里的 addCommand 没有声明 hotkeys，需要快捷键请自行到「设置 → 快捷键」绑定。命令面板本身由 Obsidian 提供，不是插件命令。

注意事项

Important

不要在手机 / 平板上依赖本插件。创作面板、时空、CSS 片段、导出都按桌面交互编写。

注意事项

  • 开发构建：生产输出在本目录；开发输出在测试库 .obsidian/plugins/novel-kit/。
  • 试验功能请用空库，避免误改正式稿件（与 Obsidian 插件教程 同一原则）。

通用限制

  • 本插件 manifest 声明 isDesktopOnly: true，最低 Obsidian 1.8.7；笔记始终是明文 Markdown，插件只读写 frontmatter 与 System/*.json。
  • 插件没有为任何命令注册默认快捷键，需要快捷键请到「设置 → 快捷键」按命令名搜索后自行绑定。
