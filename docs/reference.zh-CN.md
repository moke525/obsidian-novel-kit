## 作品工作区

**工作区**＝库内一个作品根文件夹。作品列表与当前激活作品保存在插件 `data.json` 的 `novel` 段。

### 脚手架目录

```text
我的小说/
  设定/          # 角色、地点、道具、功法、宗门、资源…
  事件/          # 场景 / 章节 / 情节（大纲）
  正文/          # 成稿（词频、字数、高亮默认看这里）
  灵感/
  词条/          # 可选
  System/
    workspace.json / graph.json / timeline.json / home.json …
    templates/   # 文件模板（默认）
    示例导览.md  # 「加载示例」写入
    伏笔钩子剧情正文.md
```

内容以 Markdown + frontmatter 为准；视图布局与模板落在 `System/*.json`。

### 创作模式

| 模式 | 差异 |
| --- | --- |
| **简单** | 创作面板少一个「裂变」；关系图不含 pack / piece；用「标记账本」替代钩子伏笔的说法 |
| **全功能** | 全部视图，含钩子 / 伏笔节点与剧情对照 |

标记功能在两种模式里都开放（都叫「标记」）。

## 创作主页

### 组件清单

| 组件 | 内容 |
| --- | --- |
| 当前作品 | 作品状态、进度，可由此进入创作面板 |
| KPI | 全部作品字数、今日码字（净增量 `last − start` 与实际增量 `max − start`） |
| 作品状态 | 可选指标的卡片 / 图表组合 |
| 创作历程 | 按时间排的大纲流水 |
| 词频 | 当前作品的用词统计 |
| 每日码字 / 创作活跃度 | 折线图与热力图 |
| 网页表格 | 给一个图表 URL，渲染成折线图 |
| 待办清单 | 写在 `home.json`，跨会话保留 |
| 时钟 / 每日一句 | 每日一句需指定库内某个 md 作为数据源 |
| 任务 / 所有作品 | 全部作品的快捷入口与列表 |

### 主页模板编辑器

主页右上角 ⚙ → **主页模板**。窗口可拖动、可缩放。

- **左侧栏**：页面设置（顶部背景图与高度）、布局、组件、选中节点的配置。窄屏下会收成抽屉。
- **画布**：拖动节点换位置或换容器；布局类型有 **list（单列）/ grid（自适应网格）/ splitPanel（两栏分区）/ tabs（页签）**。
- 一切写进 `System/home.json`：`templates` 存模板树，`activeTemplateId` 记当前用哪份，`todos` 存待办。

### 两套默认模板

首次使用时按当前设备挑一份激活，**两份都在**，随时可以切回宽屏版。

| 模板 | 适用 | 结构 |
| --- | --- | --- |
| **默认布局** | 宽屏 | 多层 splitPanel：上中下分区 + 左右分栏 |
| **移动端布局** | 手机 / 窄屏 | 单列 list 纵向滚动 + 自适应网格 + 页签折叠数据区，不含 splitPanel |

移动端不用 splitPanel 的原因：390px 的屏横向切分后，右栏只剩几十像素宽，图表会挤成竖线。

## 创作面板七个视图

顶部：作品下拉 + 刷新 → 一层视图 Tab：**关系图 · 时间线 · 裂变 · 地图 · 时空 · 卡片 · 表格**。

| 视图 | 作用摘要 |
| --- | --- |
| **关系图** | 关系图：`关系` 字段关系、组织架构、pack / piece 下钻；橙口伏笔 / 蓝口钩子为可视化。工具栏「筛选」管可见性与特殊样式，「显示配置」管类型映射与配色 |
| **时间线** | 按时间编排场景 / 章节 / 情节；分组方式选「文件夹」时拖动会移动真实文件 |
| **裂变** | 树状多列卡片大纲（默认看 `事件/`）。简单模式下不出现 |
| **地图** | 底图标记；时空视图依赖至少一张地图 |
| **时空** | 三维：x / y = 地图，z = 时间；可按角色开轨迹模式 |
| **卡片** | 可配置字段墙；模板编辑器里挑字段与控件 |
| **表格** | 分组、过滤、钉住列、编辑字段；筛选规则与关系图共用同一套规则组件 |

**高亮设置**不在创作面板里：到 **设置 → 高亮设置** 配置（全局，对所有已注册作品生效）。词表可收集全部已注册作品；旧版作品内的 `System/highlight.json` 会在需要时导入一次。

## 伏笔 · 钩子 · 剧情 · 正文

**主操作在正文里完成。** 关系图等视图只是可视化辅助。

| | 正文 | 伏笔 | 钩子 | 剧情 |
| --- | --- | --- | --- | --- |
| 作用 | 成稿与埋线入口 | 埋线索 | 回收线索 | 对照大纲 |
| 操作 | `{作品}/正文/` 框选、右键 | 正文新建 / 定位 / 编辑 | 同上 | Ribbon scroll-text（只读） |

状态以伏笔为主条目：**未埋设 → 已埋设 → 已关联 → 已回收**（外加异常态 **悬空**）。一条伏笔可以被多个钩子回指。

推荐顺序：生成或关联正文 → 成稿框选新建 / 定位 → 编辑弹窗做关联 → 写稿开剧情 → 伏笔总览验收 → 需要时再看关系图。

细则见作品内 `System/伏笔钩子剧情正文.md`。

## 全局能力

下列能力**不限当前激活作品**（在已注册作品目录内或库级生效）。

### 文件模板

**设置 → 文件模板**。规则字段：目标文件夹、文件名格式、可选模板文件、取名工具、自动填充。

- 有模板文件 → 写入正文并按格式重命名；没有 → **只按文件名格式重命名**。
- 序号：`{n}/{nn}/{nnn}` 阿拉伯数字；`{N}/{NN}/{NNN}` 中文数字（如 `第{N}章` → 第一章）。
- 在任意已注册作品的目标文件夹（含子目录）新建 md 时套用。

### 高亮设置

全局配置；词表来自全部已注册作品（及共享源卷）。命令「开关高亮设置」可快速开关。

### 在新标签页打开文件

**设置 → 小说创作**。开启后，从文件树、链接或插件视图打开文件一律走新标签。

### 历史快照

自动 / 手动存档当前笔记；面板可浏览、对比、恢复。对比默认：**左 = 历史快照（删除标红）**，**右 = 当前文件（新增标绿）**。

### 导出（当前隐藏）

把作品导出为 PDF / DOCX 等。**当前版本已隐藏**（入口全隐藏、代码保留，见 `src/main.ts` 顶部注释）；恢复时放开 `main.ts` 与 `obsidian/settings/global.svelte` 三处注释即可。

### 写作模式（打字机）

编辑时保持光标行居中，须在编辑模式下使用。

### 文件树排序

库级排序：中文数字、自然数、自定义词序。

### 高级搜索 / JSON Studio / CSS 片段

全文搜索与替换；树形编辑 `System/*.json`；管理 `.obsidian/snippets`。CSS 片段依赖桌面能力，移动端不显示。

**设置 → 小说创作 → 共享设定组**：多部作品共用世界观，组内只读引用设定（及可选时代 / 场景）。共享文件不离开源卷，视图中带共享标记，禁止误改。

## 移动端

**本插件基于桌面版开发，建议在桌面端使用。** 移动端只做了基础适配——保证能打开、能读、能改，
但排版密度与交互（拖拽、右键菜单、多面板并排）都是按桌面设计的，手机上会明显打折。
下表是移动端已经做过的适配项，不是「移动端也全功能可用」的承诺。

| 场景 | 行为 |
| --- | --- |
| **CSS 片段、导出** | 依赖 Electron 与打印能力，设置页签与入口整体不出现（导出当前**额外隐藏**，代码保留） |
| **主页布局** | 首次进入自动激活「移动端布局」（单列 + 自适应网格 + 页签）；可手动切回宽屏版 |
| **主页模板编辑器 / 卡片模板编辑器** | 左侧栏变成浮层抽屉，默认收起，标题栏按钮拉出 / 收回 |
| **关系图 / 时间线 / 时空的检查器** | 窄屏浮到画布之上，可拖边收纳，不再挤占画布宽度 |
| **高级搜索** | 停靠右侧栏（移动端左侧栏是抽屉式主导航，会被面板挤掉） |
| **词条配置面板** | 窄屏解除锚点定位，按屏幕宽度居中 |
| **词条 / 标记账本 / 灵感 / 剧情 / 伏笔总览** | 单列排版，直接可用 |

## 推荐工作流

1. 在 **正文** 写稿；需要大纲时再生成或关联情节。
2. 框选埋设 / 回收句 → 新建并定位 → 编辑弹窗挂钩子与伏笔。
3. 写稿开 **剧情**；用 **伏笔总览** 扫未回收；点高亮可滚到卡片。
4. 需要看关系 / 节奏 / 空间时再开关系图、时间线、裂变、地图、时空。
5. 用表格 / 卡片核字段、词频查用词、校对看疑错、码字看目标、手机预览看排版；重要节点手动存快照。

灵感 → 拖到关系图 / 时间线 / 裂变 → 补全字段 → 生成正文 → **仍回成稿框选定位**。

## 常见问题

### 一开始怎么用？

- **怎么新建一部小说？**  
  打开创作主页点「新增作品」，或用命令「注册小说工作区」。作品文件夹里会自动生成 `设定/`、`事件/`、`正文/`、`System/` 等目录。

- **面板是空的 / 下拉里没有作品？**  
  先确认已注册作品，并在创作面板顶部选中它。换库或换电脑后需要重新打开对应 Vault 并启用插件。

- **看不到「加载示例」？**  
  它只在**库里没有任何作品工作区**时出现。

### 关系图里怎么看不见笔记？

- **刚建的角色当时能看见，重启后就没了？**  
  关系图默认「仅显示有关联」。没有关系、参与者等关联的节点会被藏起来。关掉该选项，或先给笔记加上关联。

- **场景在，里面的章节 / 情节看不见？**  
  多半是父场景也被「仅关联」藏住了，或还没进入场景内部。先让场景出现在图上，再双击进入 pack；或关闭「仅显示有关联」。

- **某一类（角色 / 地点等）整类都不显示？**  
  打开工具栏的「筛选」或「显示配置」，勾选对应的文件类型。

### 地图 · 时空 · 时间线

- **地点改到另一张地图后，新地图上看不到标记？**  
  检查该地图的显示类型是否包含 `locale`，以及笔记里的坐标是否写成「地图名：x，y」（**冒号、逗号都是全角**），地图名要与地图标题一致。

- **时空视图里事件列表有，三维里找不到？**  
  先选一张地图，且情节要能对应到带坐标的地点。

- **时间线上改了起止，保存后没变？**  
  直接打开对应笔记，改 frontmatter 里的「开始」「结束」。

- **把条目拖到另一行，文件夹里文件怎么没动？**  
  只有分组方式选「文件夹」时才会移动 `事件/` 下的真实路径；按字段分组只改显示位置。

### 写作与侧栏

- **正文里框选文字，埋设伏笔 / 钩子没反应？**  
  请在已注册作品的 `正文/` 目录下编辑，并确认设置里「小说创作」已开启。

- **共享设定组里的笔记为什么改不了？**  
  共享内容在本作品中是只读展示，请到源作品里修改。

- **某个侧栏入口找不到？**  
  看左侧 Ribbon 或命令面板搜功能名；部分模块要在 **设置 → Novel-kit** 里先打开。

- **字数、今日进度对不上？**  
  主页统计的是当前作品工作区内的正文。确认选中的是正确作品，并刷新一次。

### 导出 · 模板 · 其它

- **导出入口找不到？**  
  导出功能**当前版本已隐藏**（入口全隐藏、代码保留），这是预期行为；后续版本会重新开放。

- **新建文件没有套模板 / 名字不对？**  
  检查「文件模板」的规则与模板目录；取名映射也在同一区域。

- **写作模式不居中？**  
  打开「写作模式」，并确认当前处在编辑模式（非预览）。

### 移动端

- **手机上少了两个设置页签？**  
  CSS 片段与导出依赖桌面能力，移动端整体不注册；且导出当前在桌面端也已隐藏，这是预期行为。

- **手机上主页看起来被压缩了？**  
  到主页模板里确认当前用的是「移动端布局」；也可以在桌面端把「默认布局」拖出一版更适合窄屏的。

若以上都试过仍异常：在创作面板点刷新，或命令面板执行「重建当前作品节点图」；并确认网盘 / 同步没有把 `System/` 下的配置文件回滚。

## 数据存放在哪

| 内容 | 位置 |
| --- | --- |
| 作品列表、当前激活作品、全局设置 | 插件 `data.json`（`.obsidian/plugins/novel-kit/data.json`）的 `novel` 等段 |
| 视图布局、筛选规则、主页模板、待办 | 该作品 `System/*.json`（graph / timeline / fission / table / cards / home …） |
| 设定、事件、正文、灵感、词条 | 作品文件夹下的 Markdown 笔记本身 |
| 悬浮便签 | 作品的 `System/` 下 |
| 历史快照 | 快照目录（见「历史快照」页签的保留策略） |

删掉插件 `data.json` 会丢失作品注册信息与全局设置，**笔记内容不受影响**；删掉某个作品的 `System/*.json` 只会重置那一小部分视图配置。

## 网络使用

**插件不收集遥测、不上传任何笔记，全部功能离线可用**。只有下列功能会联网，且都由你主动触发：

| 功能 | 触发方式 | 请求的目标 | 说明 |
| --- | --- | --- | --- |
| 词频分词词典 | 设置里点「下载」某本词典 | `cdn.jsdelivr.net`（jieba 小/标准/大词典）、`www.mdbg.net`（CC-CEDICT） | 只下载，存到 `.obsidian/plugins/novel-kit/word-freq-dicts/` |
| 主页「网页表格」组件 | 填入网址后点「获取」 | 你自己填的那个网址 | 抓取该页 HTML，在主页里解析成表格 |

两条路径都只**读远端**、不回传数据。不下载词典时，词频仍可用内置停用词表工作，只是分词精度会下降。

请求一律走 Obsidian 的 `requestUrl`，因此遵守应用内配置的代理与绕过规则。

## 开发说明

入口 `src/main.ts`：加载汇总设置后逐个初始化 feature manager。

```text
novel · wordcount · naming-kit · json-studio · vault-search · phone-preview ·
file-tree-sort · css-snippets · export · snapshot · typewriter
```

其中只有 `css-snippets`、`export` 是**桌面专属**（`Platform.isDesktop` 守卫，且不出现在移动端的设置页签里）。

`file-templates` 以设置模块形式挂载，供新建文件与脚手架调用。

```text
src/
  main.ts
  features/     # 功能模块
  ui/           # 通用组件
  I18N/         # zh-CN / en
  obsidian/     # 设置、解析、类型
  utils/
scripts/        # 5 个工具脚本（见下）
tests/
  unit/         # vitest：主页模板 / 示例数据 / 样式规约
  visual/       # 视觉回归（截图逐像素比对）
```

### 校验命令

| 命令 | 作用 |
| --- | --- |
| `npm test` | 全部 vitest 用例（主页模板 / 示例数据 / 样式规约） |
| `npm run check` | svelte-check 类型检查 |
| `npm run check:ui-style` | 单独跑样式规约（R7–R10 必须为 0，R1–R6 不许增） |
| `npm run visual:check` | 视觉回归，须先 `npm run build` |
| `npm run visual:smoke` | 自证：往样式里注入改动，必须被检出 |
| `npm run lint` / `npm run format` | Biome |

`scripts/` 里保留的都是**现役**工具：`gen-theme-vars.ts`（令牌清单生成）、
`patch-vendor-types.mjs`（postinstall 补类型）、`visual-skin.mjs`（换肤复验）、
`ui-style-report.ts`（样式规约的列表 / 基线报告）、`extract-obsidian-tokens.py`（提取 Obsidian 真实令牌）。

### 几条约定

- 开发产物落在 `test-vault/.obsidian/plugins/novel-kit/`，不要直接改用户的 Vault。
- **插件内一律用 Obsidian 的 `requestUrl` 而不是裸 `fetch`** —— 只有前者会尊重 Obsidian 的代理绕过列表。
- 新功能的标准模子：`src/features/<名>/` 里放 `manager.ts` + `appView.ts` + `settings.ts`，再到 `main.ts` 注册。
- UI 组件库在 `src/ui/components/`，动手写新组件前先查一遍。
